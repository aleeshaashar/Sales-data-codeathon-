# Sales-data-codeathon-
Data Analysis &amp; Visualization
Data Analysis & Visualization Project

This project focuses on data cleaning, transformation, analysis, and visualization using a sales dataset.

Key Tasks Completed

- Removed duplicate records and handled null/missing values.
- Cleaned and transformed the dataset for analysis.
- Created calculated columns and measures.
- Created and organized data tables for analysis.
- Built visualizations including Line Chart, Pie Chart, and Column Chart.
- Analyzed the cleaned data to identify useful sales insights.

The project demonstrates the complete process from data cleaning to analysis and visualization.
